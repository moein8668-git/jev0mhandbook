# کتاب کاربردی TypeSafe، Jev و Laya

برای مطالعه، index.html را در مرورگر باز کنید.
این فایل به کتابخانه، فونت یا سرویس اینترنتی وابسته نیست.
منابع بیرونی و اتصال زندهٔ مدل به اینترنت یا سرویس مربوط نیاز دارند.

## محتوای کتاب

- ۳۴ فصل
- ۱۰٬۳۲۰ واژهٔ توضیح بدون احتساب کد
- زمان مطالعهٔ تخمینی: ۵۲ تا ۶۵ دقیقه با سرعت ۱۶۰ تا ۲۰۰ واژه در دقیقه
- ۲۹۹۸ خط HTML
- جست‌وجوی فصل‌ها، حالت روشن/تیره، کپی کد، چاپ و دو آزمایش تعاملی

## اجرای مثال

از پوشهٔ examples، با Python 3.10 یا جدیدتر:

    python support_router.py
    python -m unittest -v test_support_router.py

حالت پیش‌فرض fixture است و مدل را اجرا نمی‌کند.
تغییر پیام در این حالت، خروجی مدل ساختگی را تغییر نمی‌دهد.

برای اتصال واقعی، متغیر محیطی TYPESAFE_API_KEY را روی سرور تنظیم کنید:

    python support_router.py --live --message "Please connect me with a support specialist."

مثال از کتابخانهٔ استاندارد Python استفاده می‌کند.
اتصال واقعی به کلید معتبر، شبکه و حساب دارای دسترسی نیاز دارد.
آستانه‌ها آموزشی‌اند و باید روی دادهٔ واقعی ارزیابی شوند.

## بررسی انجام‌شده

چهارده آزمون محلی پروژه پاس شده‌اند.
نمایش در Chrome، موبایل ۳۹۰ پیکسل و دسکتاپ ۱۴۴۰ پیکسل بررسی شده است.
جست‌وجو، آستانه‌های تعاملی، محاسبهٔ Score و تغییر تم آزموده شده‌اند.
لینک‌های داخلی و جهت RTL/LTR بررسی شده‌اند.
اتصال زندهٔ TypeSafe یا دانلود/اجرای وزن تازهٔ Laya انجام نشده است.
